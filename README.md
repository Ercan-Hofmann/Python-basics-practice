# Python-basics-practice
Python practice projects covering fundamental programming concepts .

## Number Comparison Program
This is my first Python practice project.
The program:
- Asks the user for their name
- Uses string manipulation with `strip()` and `title()`
- Takes two numbers as input
- Compares the numbers using `if`, `elif`, and `else`
- Finds the smaller and larger number using `min()` and `max()`
- Uses a `for` loop and `range()` to display the numbers
- Calculates the total of all numbers in the range

 
## What I Learned
Through this project, I practiced:
- Working with user input
- Converting input with `int()`
- String manipulation
- Conditional statements
- `for` loops and `range()`
- Variables and basic calculations
- Using `min()` and `max()`

## How to Run
Run the program from the terminal:
```bash
python number_comparison.py
```
